# Django Employee Management System with Authentication & Authorization

This project is a **Django-based web application** that implements **full CRUD** (Create, Read, Update, Delete) operations for managing employee details. It also includes **authentication** and **authorization** using session-based role access. The system uses **Django templates and custom tags**, along with **CSS styles** via static files.

---

## 🔧 Features

- ✅ **Employee CRUD Operations**  
  - Create, Read, Update, and Delete employee details.

- ✅ **Authentication & Authorization**  
  - Users can **register**, **login**, and **logout**.
  - Role-based access control: Only **authorized users** can perform certain actions.

- ✅ **Template Usage**  
  - Use of Django templates to render HTML views.
  - **Template inheritance** for reusability.

- ✅ **Custom Template Tags**  
  - Use of custom template tags for dynamic content rendering.

- ✅ **Filtering**  
  - Employees can be **filtered** by different parameters (e.g., department, job title).

- ✅ **CSS Styles**  
  - Styling is done using **static CSS files** integrated into Django templates.
